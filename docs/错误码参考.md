# 错误码参考

NexMesh 错误码体系：**客户端错误 40xxx / 服务端错误 50xxx**，HTTP 状态码与错误码前缀对齐。

所有错误以 `ApiResult` JSON 返回：

```json
{ "code": 40001, "message": "参数 id 格式错误：\"abc\" 无法转换为 Int64", "data": null, "succeeded": false }
```

响应头含 `X-Trace-Id`，可关联服务端日志定位。

---

## 40xxx 客户端错误

| 码 | HTTP | 场景 | 消息示例 |
|---|---|---|---|
| 40000 | 400 | MeshException 默认码 | 业务异常未指定码 |
| 40001 | 400 | 参数/JSON/表单格式错误 | `参数 id 格式错误:"abc" 无法转换为 Int64` |
| 40002 | 400 | 工作流步骤列表为空 | `工作流步骤列表为空,拒绝启动` |
| 40101 | 401 | Token 无效/过期/需登录 | `访问令牌无效、已过期或已吊销` |
| 40102 | 401 | 用户名或密码错误 | `用户名或密码错误` |
| 40400 | 404 | 网关逻辑路由未注册 | `逻辑路由 '/api/xxx' 未注册` |
| 40401 | 404 | 审批单/工作流不存在 | `审批单 {id} 不存在` |
| 40500 | 405 | 网关路由动词不支持 | `逻辑路由 '/api/xxx' 不支持 POST` |
| 40901 | 409 | 幂等冲突 | `重复请求处理中(Idempotency-Key 冲突)` |
| 40902 | 409 | 乐观并发冲突 | `数据已被他人修改,请刷新后重试` |
| 40903 | 409 | 审批单状态冲突 | `审批单 {id} 已处于 Executed 状态,不可重复决策` |
| 40904 | 409 | 工作流状态不符 | `工作流 {id} 状态为 Running,仅 Suspended 可恢复` |
| 40905 | 409 | 工作流恢复竞态 | `工作流 {id} 已被恢复或状态已变更` |
| 40906 | 409 | 工作流步骤签名变更 | `工作流 {id} 的步骤定义已变更,拒绝恢复` |
| 42901 | 429 | 登录限流 | `登录尝试过于频繁,请稍后再试` |

## 50xxx 服务端错误

| 码 | HTTP | 场景 | 消息示例 |
|---|---|---|---|
| 50000 | 500 | 未知异常（兜底） | `服务器内部错误(TraceId:xxx)` |
| 50001 | 500 | 表单类型实例化失败 | `无法实例化表单类型 XxxForm` |
| 50002 | 500 | 审批执行失败：工具不可用 | `审批执行失败:工具 X 已不可用` |
| 50003 | 500 | 工作流输入类型不匹配 | `工作流输入 'count' 类型不匹配:期望 Int32,实际 JsonElement` |
| 50004 | 500 | 未配置 ILoginValidator | `未配置 ILoginValidator,业务侧需实现并注册登录验证` |
| 50005 | 500 | 工作流序列化失败 | `工作流 xxx 的步骤输出不可 JSON 序列化` |

## 使用指南

### 业务代码中抛异常

```csharp
// 自动返回 400 + {"code":40001,"message":"金额必须大于 0"}
throw new MeshException("金额必须大于 0", errorCode: 40001, statusCode: 400);

// 自定义错误码(业务区间建议 41xxx~49xxx)
throw new MeshException("库存不足", errorCode: 41001, statusCode: 422);
```

### 前端统一处理

```javascript
const res = await fetch(url);
const body = await res.json();

if (!body.succeeded) {
    // body.code: 40001 参数错 / 40101 需登录 / 40901 重复请求 / 42901 限流
    console.error(`[${body.code}] ${body.message}`, res.headers.get('X-Trace-Id'));
}
```

---

## 注意事项

- `50000` 是唯一不暴露内部细节的服务端错误码——`ex.Message` 仅入日志，不回传客户端
- 40001 是参数绑定的聚合码（简单参数/JSON Body/集合元素/表单字段共用），排查时看 message 中的字段名
- `MeshException` 未指定 `errorCode` 时默认 40000，未指定 `statusCode` 时默认 400
- 错误码全局唯一语义：每个码只对应一种业务场景，不可复用
