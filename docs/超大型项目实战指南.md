## 一、项目规划

假设我们要建一个「企业订单管理系统」:

```
MyCompany.OrderService/           ← 订单服务(本文要搭建的)
├── Program.cs                    ← 启动接线
├── Features/                     ← 业务模块(垂直切片)
│   ├── Orders/                   ← 订单模块
│   │   ├── Order.cs              ← 实体
│   │   ├── OrderContracts.cs     ← DTO + 事件
│   │   ├── OrderApi.cs           ← API 接口 + 实现
│   │   ├── OrderService.cs       ← 领域服务(复杂业务逻辑)
│   │   └── OrderCreatedHandler.cs ← 事件处理器
│   ├── Products/                 ← 商品模块
│   └── Customers/                ← 客户模块
├── Scripts/                      ← SQL 迁移脚本
│   ├── V001__create_tables.sql
│   └── V002__seed_data.sql
├── appsettings.json
├── appsettings.Development.json
└── Dockerfile
```

**为什么这样组织?** 一个功能一个文件夹(垂直切片),新人只需要看一个文件夹就能理解一个模块。不像传统分层(Controller/Service/Repository 各一个目录),改一个功能要跳四个目录。

## 二、创建项目

```bash
# 1. 创建项目
dotnet new webapi -n MyCompany.OrderService
cd MyCompany.OrderService

# 2. 装 NexMesh 包
# 先在 NexMesh 仓库根目录打包:
#   dotnet pack src/NexMesh.Core -o artifacts/nupkgs
#   dotnet pack src/NexMesh.Data.FreeSql -o artifacts/nupkgs
#   ... 其他包同理

# 3. 在项目目录创建 NuGet.config(指向本地包)
cat > NuGet.config <<EOF
<?xml version="1.0" encoding="utf-8"?>
<configuration>
  <packageSources>
    <clear />
    <add key="nexmesh-local" value="C:/path/to/NexMesh/artifacts/nupkgs" />
    <add key="nuget" value="https://api.nuget.org/v3/index.json" />
  </packageSources>
</configuration>

# 4. 装包
```

## 三、基础设施搭建

### Program.cs(完整版)

```csharp
using FreeSql;
using NexMesh.Auth;
using NexMesh.Cache.FreeRedis;
using NexMesh.Core;
using NexMesh.Data.FreeSql;
using NexMesh.Data.Migrations;
using NexMesh.Events;
using NexMesh.Mapping;
using NexMesh.Observability;
using NexMesh.Resilience;
using NexMesh.Toolbox;
using NexMesh.Web.Scalar;

var builder = WebApplication.CreateBuilder(args);

// ══════════════════════════════════════════════════════
// 基础设施(每个服务都有这段,照抄)
// ══════════════════════════════════════════════════════

// 日志:Serilog 控制台 JSON(零配置)
builder.AddNexMeshObservability();

// 核心:统一响应/异常/健康检查/ICurrentUser/ICurrentTenant
builder.Services.AddNexMesh();

// 数据库:MySQL(生产)/ SQLite(开发可用)
builder.Services.AddNexMeshDb("main", o =>
{
    o.DataType = DataType.MySql;
    o.MasterConnectionString = builder.Configuration.GetConnectionString("Main")!;
    o.UseAutoSyncStructure = builder.Environment.IsDevelopment();
    o.EnableSoftDeleteFilter = true;     // 软删除
    o.EnableAudit = true;                // 审计
    o.EnableTenantFilter = true;         // 多租户
    o.Slaves = [builder.Configuration.GetConnectionString("Slave")!];  // 读分离
});

// 缓存:没配 Redis 自动用内存
builder.Services.AddNexMeshCache(builder.Configuration);

// 认证:JWT
builder.Services.AddNexMeshJwt(builder.Configuration);

// 事件:进程内(开发)/ RabbitMQ(生产)
builder.Services.AddNexMeshEvents(builder.Configuration);

// 对象映射
builder.Services.AddNexMeshMapping(config =>
{
    config.NewConfig<Order, OrderDto>();
    config.NewConfig<Product, ProductDto>();
});

// 分布式 ID
// 限流
builder.Services.AddNexMeshRateLimiter(builder.Configuration);
builder.Services.AddNexMeshIds(workerId: 1);  // 每个实例不同(0-63)

// HTTP 弹性(调第三方 API 自动重试/熔断)
builder.Services.AddNexMeshResilience();

// API 文档
builder.Services.AddNexMeshDocs();

// 数据库迁移
builder.Services.AddNexMeshMigrations();

// ══════════════════════════════════════════════════════
// 业务模块(每个模块的接口+实现+事件+种子)
// ══════════════════════════════════════════════════════

// 自动 API:扫描程序集,IAutoApi 实现类自动注册
builder.Services.AddNexMeshAutoApi();

// 事件处理器
builder.Services.AddNexMeshEventHandler<OrderCreated, SendEmailOnCreated>();
builder.Services.AddNexMeshEventHandler<OrderCreated, UpdateInventoryOnCreated>();

// 种子数据
builder.Services.AddNexMeshSeed<ProductSeed>();
builder.Services.AddNexMeshSeed<DictionarySeed>();

// 后台任务
builder.Services.AddNexMeshWorker<OrderSyncWorker>();

// ══════════════════════════════════════════════════════
// 中间件管道(顺序重要!)
// ══════════════════════════════════════════════════════

var app = builder.Build();

app.UseNexMeshTraceId();              // ① X-Trace-Id(最外层,所有响应都带)
app.UseNexMeshApiVersion();           // ② API 版本控制
app.UseNexMeshIdempotency();          // ③ 幂等防重(需缓存)
app.UseNexMeshAudit();                // ④ 审计(记录每个请求)
app.UseNexMeshExceptionHandling();    // ⑤ 全局异常 → 统一 JSON

app.UseAuthentication();              // ⑥ 认证
app.UseAuthorization();               // ⑦ 授权
app.UseRateLimiter();                 // ⑧ 限流

app.MapNexMeshAutoApi();              // ⑨ 自动 API 端点
app.MapDefaultEndpoints();            // ⑩ /health /health/live /health/ready
app.MapNexMeshDocs();                 // ⑪ /scalar + /swagger

// ══════════════════════════════════════════════════════
// 启动时执行(迁移 + 种子)
// ══════════════════════════════════════════════════════

app.ApplyNexMeshMigrations();         // SQL 迁移
app.ApplyNexMeshSeeds();              // 种子数据
app.UseNexMeshDiagnostics();          // 装配摘要 + /diagnostics

app.Run();
```

## 四、数据层

### 实体定义(Features/Orders/Order.cs)

```csharp
using NexMesh.Core;

namespace MyCompany.OrderService.Features.Orders;

/// <summary>
/// 订单实体。四个接口全部实现,获得:软删除+审计+并发保护+多租户。
/// </summary>
public class Order : ISoftDelete, IAudited, IHasConcurrencyStamp, ITenantEntity
{
    public Guid Id { get; set; }

    // 业务字段
    public string OrderNo { get; set; } = "";           // 订单号(业务编号,非主键)
    public string CustomerName { get; set; } = "";
    public string CustomerPhone { get; set; } = "";
    public decimal TotalAmount { get; set; }
    public string Status { get; set; } = "pending";     // pending/paid/shipped/completed/cancelled
    public string? Remark { get; set; }

    // 导航属性(查询时关联)
    public List<OrderItem> Items { get; set; } = [];

    // ── ISoftDelete: 删除标记,查询自动过滤 ──
    public bool IsDeleted { get; set; }

    // ── IAudited: 时间和操作人自动填 ──
    public DateTime CreatedAt { get; set; }
    public string? CreatedBy { get; set; }
    public DateTime? UpdatedAt { get; set; }
    public string? UpdatedBy { get; set; }

    // ── IHasConcurrencyStamp: 并发保护(同时改→409) ──
    public string ConcurrencyStamp { get; set; } = "";

    // ── ITenantEntity: 多租户隔离 ──
    public string? TenantId { get; set; }
}

/// <summary>订单明细(简单实体,只要软删除+审计)。</summary>
public class OrderItem : ISoftDelete, IAudited
{
    public Guid Id { get; set; }
    public Guid OrderId { get; set; }                    // 外键
    public long ProductId { get; set; }                  // 商品 ID(雪花)
    public string ProductName { get; set; } = "";
    public int Quantity { get; set; }
    public decimal UnitPrice { get; set; }
    public decimal Subtotal => Quantity * UnitPrice;     // 计算属性(不存库)

    public bool IsDeleted { get; set; }
    public DateTime CreatedAt { get; set; }
    public string? CreatedBy { get; set; }
    public DateTime? UpdatedAt { get; set; }
    public string? UpdatedBy { get; set; }
}
```

### 领域服务(Features/Orders/OrderService.cs)

```csharp
using NexMesh.Core;
using NexMesh.Data.FreeSql;
using NexMesh.Events;
using NexMesh.Toolbox;

namespace MyCompany.OrderService.Features.Orders;

/// <summary>
/// 订单领域服务:复杂业务逻辑(API 层只做参数校验和调用)。
/// </summary>
public class OrderService(
    IRepository<Order> orderRepo,
    IRepository<OrderItem> itemRepo,
    IRepository<Product> productRepo,
    INexMeshEventPublisher events,
    IIdGenerator ids,
    ICacheFactory cacheFactory)
{
    /// <summary>创建订单(校验商品、计算金额、扣库存、发事件)。</summary>
    public async Task<Order> CreateAsync(CreateOrderRequest req, string? tenantId, CancellationToken ct)
    {
        // 1. 业务校验
        if (string.IsNullOrWhiteSpace(req.CustomerName))
            throw new MeshException("客户姓名不能为空", errorCode: 40001);

        if (req.Items is null || req.Items.Count == 0)
            throw new MeshException("订单明细不能为空", errorCode: 40002);

        // 2. 查商品、校验库存
        var productIds = req.Items.Select(i => i.ProductId).ToList();
        var products = await productRepo.ListAsync(p => productIds.Contains(p.Id), ct);
        var productDict = products.ToDictionary(p => p.Id);

        decimal totalAmount = 0;
        var items = new List<OrderItem>();
        foreach (var itemReq in req.Items)
        {
            if (!productDict.TryGetValue(itemReq.ProductId, out var product))
                throw new MeshException($"商品 {itemReq.ProductId} 不存在", errorCode: 40402);

            if (product.Stock < itemReq.Quantity)
                throw new MeshException($"商品 {product.Name} 库存不足(剩余 {product.Stock})",
                    errorCode: 40903, statusCode: 409);

            // 3. 构建订单明细
            items.Add(new OrderItem
            {
                Id = ids.NextUuidV7(),
                ProductId = product.Id,
                ProductName = product.Name,
                Quantity = itemReq.Quantity,
                UnitPrice = product.Price,
                TenantId = tenantId,
            });

            totalAmount += product.Price * itemReq.Quantity;

            // 4. 扣库存
            product.Stock -= itemReq.Quantity;
            await productRepo.UpdateAsync(product, ct);
        }

        // 5. 创建订单
        var order = await orderRepo.AddAsync(new Order
        {
            Id = ids.NextUuidV7(),
            OrderNo = $"ORD{DateTime.UtcNow:yyyyMMddHHmmss}{Random.Shared.Next(1000, 9999)}",
            CustomerName = req.CustomerName,
            CustomerPhone = req.CustomerPhone,
            TotalAmount = totalAmount,
            Status = "pending",
            Remark = req.Remark,
            Items = items,
            TenantId = tenantId,
        }, ct);

        // 6. 保存明细
        await itemRepo.AddManyAsync(items, ct);

        // 7. 发布事件(发邮件/更新报表/通知库存系统)
        await events.PublishAsync(
            new OrderCreated(order.Id, order.OrderNo, order.CustomerName, order.TotalAmount), ct);

        return order;
    }

    /// <summary>修改订单状态(带并发检查)。</summary>
    public async Task ChangeStatusAsync(Guid orderId, string newStatus, string concurrencyStamp, CancellationToken ct)
    {
        var order = await orderRepo.FindAsync(orderId, ct)
            ?? throw new MeshException("订单不存在", errorCode: 40401, statusCode: 404);

        // 设置旧戳(UpdateAsync 内会校验)
        order.ConcurrencyStamp = concurrencyStamp;

        var oldStatus = order.Status;
        order.Status = newStatus;
        await orderRepo.UpdateAsync(order, ct);    // 戳不匹配自动 409

        await events.PublishAsync(new OrderStatusChanged(orderId, oldStatus, newStatus), ct);
    }

    /// <summary>分页查询订单。</summary>
    public async Task<PagedResult<Order>> SearchAsync(ListOrdersRequest req, CancellationToken ct)
    {
        var query = orderRepo.ListAsync;    // 基础查询(自动过滤软删除+租户)

        // 条件筛选
        // 分页查询:直接用 IDbFactory + ToPagedResultAsync
        return await db.Get().Select<Order>()
            .WhereIf(!string.IsNullOrEmpty(status), o => o.Status == status)
            .OrderByWhitelist(req.SortBy, req.Desc, ["CreatedAt", "TotalAmount"])
            .ToPagedResultAsync(req.PageIndex, req.PageSize, ct);
    }
}
```

## 五、API 层

> NexMesh 两种主要 API 风格:**FastEndpoints**(端点类)和**自动 API**(接口+实现类),可混用。以下两种方式都展示。

### FastEndpoints 方式(默认)

```csharp
using FastEndpoints;
using NexMesh.Core;
using NexMesh.Data.FreeSql;

public class CreateOrder(IRepository<Order> repo)
    : Endpoint<CreateOrderRequest, ApiResult<OrderDto>>
{
    public override void Configure()
    {
        Post("/api/orders");
        AllowAnonymous();
        Summary(s => s.Summary = "创建订单");
    }

    public override async Task HandleAsync(CreateOrderRequest req, CancellationToken ct)
    {
        if (req.Amount <= 0)
            throw new MeshException("金额必须大于 0", errorCode: 40002);

        var order = await repo.AddAsync(new Order { ... }, ct);
        await HttpContext.Response.SendAsync(
            ApiResult<OrderDto>.Ok(new OrderDto(...)), 201);
    }
}

// Program.cs:
builder.Services.AddFastEndpoints();
app.UseFastEndpoints();
```

### 自动 API 方式(与 FastEndpoints 可混用)

```csharp
// Features/Orders/OrderApi.cs
using Microsoft.AspNetCore.Mvc;
using NexMesh.Core;
using NexMesh.Data.FreeSql;
using NexMesh.Events;
using NexMesh.Toolbox;

namespace MyCompany.OrderService.Features.Orders;

/// <summary>
/// 订单 API。接口+实现类,不需要继承任何父类。
/// 路由:IOrderApi → /api/orders
/// </summary>
public interface IOrderApi : IAutoApi
{
    /// <summary>创建订单。</summary>
    [HttpPost]
    Task<OrderDto> CreateAsync(CreateOrderRequest req);

    /// <summary>查订单详情(带明细)。</summary>
    [HttpGet("{id:guid}")]
    Task<OrderDto> FindAsync(Guid id);

    /// <summary>分页查询订单列表。</summary>
    [HttpGet]
    Task<PagedOrdersDto> ListAsync(
        [FromQuery] int pageIndex = 1,
        [FromQuery] int pageSize = 20,
        [FromQuery] string? status = null);

    /// <summary>修改订单状态。</summary>
    [HttpPut("{id:guid}/status")]
    Task<OrderDto> ChangeStatusAsync(Guid id, UpdateOrderStatusRequest req);

    /// <summary>取消订单。</summary>
    [HttpDelete("{id:guid}")]
    Task DeleteAsync(Guid id);
}

public class OrderApi(
    OrderService service,
    IRepository<Order> repo,
    ICurrentTenant tenant,
    IMapper mapper) : IOrderApi
{
    public async Task<OrderDto> CreateAsync(CreateOrderRequest req)
    {
        var order = await service.CreateAsync(req, tenant.Id, CancellationToken.None);
        return mapper.Map<OrderDto>(order);
    }

    public async Task<OrderDto> FindAsync(Guid id)
    {
        var order = await repo.FindAsync(id)
            ?? throw new MeshException("订单不存在", errorCode: 40401, statusCode: 404);
        return mapper.Map<OrderDto>(order);
    }

    public async Task<PagedOrdersDto> ListAsync(int pageIndex, int pageSize, string? status)
    {
        var page = await db.Get().Select<Order>().Where(o => status == null || o.Status == status).ToPagedResultAsync(pageIndex, pageSize);
        return new PagedOrdersDto(
            page.Items.Select(mapper.Map<OrderDto>).ToList(),
            page.TotalCount, page.PageIndex, page.PageSize);
    }

    public async Task<OrderDto> ChangeStatusAsync(Guid id, UpdateOrderStatusRequest req)
    {
        await service.ChangeStatusAsync(id, req.Status, req.ConcurrencyStamp, CancellationToken.None);
        var order = await repo.FindAsync(id);
        return mapper.Map<OrderDto>(order!);
    }

    public async Task DeleteAsync(Guid id)
    {
        var order = await repo.FindAsync(id)
            ?? throw new MeshException("订单不存在", errorCode: 40401, statusCode: 404);
        await repo.SoftDeleteAsync(order);
    }
}
```

## 六、认证授权

### 签发 Token(登录)

```csharp
// Features/Auth/LoginApi.cs
public interface IAuthApi : IAutoApi
{
    [HttpPost("login")]
    Task<TokenResponse> LoginAsync(LoginRequest req);
}

public class AuthApi(ITokenService tokens, IRepository<User> userRepo) : IAuthApi
{
    public async Task<TokenResponse> LoginAsync(LoginRequest req)
    {
        // 验证用户名密码(实际项目中用 BCrypt 哈希比较)
        var user = await userRepo.GetAsync(u => u.Username == req.Username)
            ?? throw new MeshException("用户名或密码错误", errorCode: 40102, statusCode: 401);

        // 签发 token(带租户 ID)
        var token = tokens.Issue(new Dictionary<string, object>
        {
            ["sub"] = user.Id.ToString(),
            ["name"] = user.Username,
            ["role"] = user.Role,
            ["tenant_id"] = user.TenantId,       // 租户 ID 进 claim
        });

        return new TokenResponse(token);
    }
}

public record LoginRequest(string Username, string Password);
public record TokenResponse(string Token);
```

```csharp
// Program.cs 中间件管道里加(在认证之后):
```

## 九、缓存策略

```csharp
// 商品详情缓存(读多写少,适合缓存)
public class ProductApi(IRepository<Product> repo, ICacheFactory cache)
    : IProductApi
{
    public async Task<ProductDto> FindAsync(long id)
    {
        // 缓存 5 分钟;同 key 并发只放一个查库
        return await cache.Get().GetOrCreateAsync(
            $"product:{id}",
            TimeSpan.FromMinutes(5),
            async ct =>
            {
                var product = await repo.FindAsync(id, ct);
                return product is null ? null : MapToDto(product);
            });
    }

    // 更新后清缓存
    public async Task<ProductDto> UpdateAsync(long id, UpdateProductRequest req)
    {
        var product = await repo.FindAsync(id)
            ?? throw new MeshException("商品不存在", errorCode: 40401, statusCode: 404);

        product.Name = req.Name;
        product.Price = req.Price;
        await repo.UpdateAsync(product);

        await cache.Get().RemoveAsync($"product:{id}");    // ← 别忘了清缓存!
        return MapToDto(product);
    }
}
```

## 十一、后台任务

```csharp
// Features/Orders/OrderSyncWorker.cs

/// <summary>
/// 订单同步工作者:每 5 分钟检查一次超时未支付订单,自动取消。
/// </summary>
public class OrderTimeoutWorker(
    IServiceScopeFactory scopeFactory,
    ILogger<OrderTimeoutWorker> logger)
    : NexMeshPeriodicWorker(TimeSpan.FromMinutes(5), scopeFactory, logger)
{
    protected override async Task RunOnceAsync(IServiceProvider scoped, CancellationToken ct)
    {
        var repo = scoped.GetRequiredService<IRepository<Order>>();
        var events = scoped.GetRequiredService<INexMeshEventPublisher>();

        // 查找 30 分钟前创建且仍为 pending 的订单
        var cutoff = DateTime.UtcNow.AddMinutes(-30);
        var timeoutOrders = await repo.ListAsync(
            o => o.Status == "pending" && o.CreatedAt < cutoff, ct);

        foreach (var order in timeoutOrders)
        {
            order.Status = "cancelled";
            order.Remark = "超时未支付,自动取消";
            await repo.UpdateAsync(order, ct);

            await events.PublishAsync(
                new OrderStatusChanged(order.Id, "pending", "cancelled"), ct);
        }

        if (timeoutOrders.Count > 0)
        {
            logger.LogInformation("[WORKER] 超时取消 {Count} 个订单", timeoutOrders.Count);
        }
    }
}

// 注册(在 Program.cs)
builder.Services.AddNexMeshWorker<OrderTimeoutWorker>();
```

## 十六、团队协作规范

### 新人上手

1. 读 README(从"第一步:跑起来"开始)
2. 跑通 Demo(samples/ReferenceService)
3. 读 [开发规范](standards/00-规范总览.md)(重点看 01 分层、04 错误处理、10 数据访问)
4. 读本文(实战指南)
5. 从一个简单模块开始(如商品 CRUD)

### PR 合并检查

- [ ] `dotnet build` 零警告
- [ ] `dotnet test` 全绿
- [ ] 新端点走 `/api/{resource}` 命名
- [ ] DTO 不暴露实体内部字段
- [ ] 错误码已登记 `docs/errorcodes.md`
- [ ] 分页用 `PagedResult` + 排序白名单
- [ ] 缓存写后清
- [ ] 事件在事务提交后发布
- [ ] 后台任务响应取消
- [ ] 生产密钥不入库

### 代码审查重点

1. **分层**:端点只做参数校验+调用 Service;Service 做业务逻辑
2. **命名**:DTO 用 record;事件用过去式(OrderCreated)
3. **安全**:密钥从环境变量;日志敏感字段脱敏
4. **性能**:分页必须走 ToPagedResultAsync(不裸查全表);缓存读走 GetOrCreateAsync
