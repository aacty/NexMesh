# NexMesh 架构白皮书

> 基于白皮书审核（[history/审核-NexMesh.AI白皮书-v1.0.0.md](history/审核-NexMesh.AI白皮书-v1.0.0.md)）的修正结论，经双轮 SSS+ 安全审查后的最终架构。

---

## 一、设计哲学

**你只写业务代码，框架处理其余一切。**

| 开发者不写 | 框架处理 |
|---|---|
| DI 注册（AddScoped/AddTransient） | 标记接口自动扫描注册 |
| 生命周期心智 | `IScopedService` 一个标签即完事 |
| 路由表与参数绑定配置 | `[Http*]` 标注自动映射 |
| 数据库接线（连接串/Provider/建表） | `NexMesh:Db` 配置节驱动 |
| AI Provider 管道（Key/模型/重试） | `NexMesh:AI` 配置节驱动 |
| 中间件顺序 | `UseNexMeshService()` 一行 |
| Token 过期/续期/吊销 | 框架内置 |
| 高危操作审批 | `[NexMeshTool(描述, High)]` 一个参数 |
| 跨线程身份/租户传递 | 快照显式绑定 |
| 大模型 JSON 参数错配 | 自纠错回喂 |
| 断连后模型继续烧钱 | 断连熔断守卫 |

```
NexMesh.Core        → (无)
NexMesh.AI          → (无，零项目引用)
NexMesh.AI.Approval → AI + Core
```

**铁律**：AI 核心零引用 Data/Auth/Cache/Workflow；依赖全部单向朝下；无循环依赖。

## 四、HTTP 请求执行顺序

```
① 认证 Handler        Bearer → 会话 → 滑动续期 → ClaimsPrincipal
② 无效凭据拒绝闸       带了 Bearer 但无效 → 401(40101)，绝不静默降级
③ 授权中间件          [Authorize] 元数据 → 未登录 401 / 无权限 403
④ 上下文快照          User → NexMeshContext(AsyncLocal) + TenantHelper
⑤ 异常中间件          X-Trace-Id + MeshException 业务码透传 / 未知 50000
⑥ CORS
⑦ 路由匹配 → AutoApiDispatcher → 参数绑定 → 业务方法
```

## 六、数据层约定接口

| 接口 | 自动行为 |
|---|---|
| `ISoftDelete` | 全局过滤排除已删；`SoftDeleteAsync` 只标记不物理删 |
| `IAudited` | CreateTime/UpdateTime 写入路径自动填充 |
| `IUserAudited` | 操作人从 ICurrentUser 自动填充 |
| `IHasConcurrencyStamp` | 更新校验戳，冲突 → 40902/409 |
| `ITenantEntity` | 全局过滤限定当前租户；写入自动填充 TenantId |
| long 主键为 0 | 雪花 ID 接管（非自增）；自增由数据库分配 |

## 七、上下文显式绑定（跨线程/离线断链处理）

```
触发时(请求内): Capture() → NexMeshContext(不可变快照)
     ↓ 序列化进消息头/工作流状态/审批单
执行时(离线):  Enter(snapshot) → AsyncLocal 显式绑定 → Dispose 还原先前值

五步纪律(BackgroundRunner):
① Activity Consumer Span 接续(断链2)
② Enter 显式绑定 AsyncLocal(断链1)
③ 独立 DI 作用域(断链4)
④ CancellationToken = 调用方令牌 + 停机令牌(断链3)
⑤ 作用域/环境槽/Activity 全部还原
```

---

## 八、并发安全三铁律

1. **环境槽退出必须"还原先前值"，严禁置空**——AsyncLocal 随 ExecutionContext 流动，置空破坏嵌套绑定。
2. **严禁把 `HttpContext.RequestAborted` 传入后台任务**——后台令牌 = 调用方令牌 + `ApplicationStopping`。
3. **严禁闭包捕获请求作用域的 Scoped 服务**——离线代码只从 Runner 注入的全新作用域解析依赖。

## 九、三层防御详解

### 大模型吸血鬼效应（Token 浪费）

用户关闭浏览器 → `RequestAborted` 触发 → 断连熔断守卫终止模型流/函数调用/计费。离线任务退化为透传（由 Runner 停机令牌接管）。

### 上下文穿帮（跨租户数据泄露）

20 并发异步流各自绑定不同身份（AsyncLocal），线程池复用下互不可见——有专项测试锁定。

### 大模型 JSON 与强类型契约错配

反序列化/执行异常 → `[NexMesh Tool Error]` 结构化错误文本回喂模型 → 模型反思修正参数重试 → 禁止编造结果。取消类异常仍上抛（熔断语义优先）。
