# 配置参考

> 全部配置节都在本文;不确定怎么写时,先从下面的模板复制一份,再按需删改。

## 可直接复制的配置模板

**开发环境(SQLite + 离线 AI,零外部依赖)**:

```json
{
  "NexMesh": {
    "Db": { "Type": "Sqlite", "ConnectionString": "Data Source=app.db", "AutoSyncStructure": true },
    "AI": {
      "DefaultProvider": "main",
      "Providers": { "main": { "Type": "stub", "Model": "stub" } }
    }
  }
}
```

**生产环境要点**(逐项确认后再上线):数据库连接换成正式库且关闭 `AutoSyncStructure`;AI 换真实 Provider 并用 `${ENV|}` 占位符管理 Key;认证配 Redis 共享会话;按需开启 CORS 白名单。各节详细说明见下文。

NexMesh 全部配置节使用 `NexMesh:` 前缀。支持三种来源（优先级从低到高）：`Configs/*.json` → 环境变量 → 命令行参数。

## 配置文件约定

```
Configs/
├── app.json              # 基础配置
├── app.Development.json  # 开发环境覆盖（可选）
├── ai.json               # AI 相关（推荐独立文件）
├── auth.json             # 认证相关
└── db.json               # 数据库
```

环境变量命名规则：`NexMesh:AI:Providers:main:ApiKey` → `NexMesh__AI__Providers__main__ApiKey`

## 占位符

所有配置值支持 `${环境变量名|默认值}` 占位符：

```json
{ "ApiKey": "${NEXMESH_DEEPSEEK_KEY|}" }
```

- 环境变量存在 → 使用环境变量值
- 不存在 → 使用竖线后的默认值（`|}` 即空串）
- 热更新：json 文件修改后自动重载（reloadOnChange）

## NexMesh:Db（数据层）

| 键 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| Type | string | Sqlite | FreeSql 数据库类型（PostgreSQL/MySql/SqlServer/Sqlite） |
| ConnectionString | string | Data Source=app.db | 连接串 |
| AutoSyncStructure | bool | 开发=true | CodeFirst 自动建表 |
| WorkerId | int | 1 | 雪花 ID 节点号（集群内唯一，0~1023） |

```json
{
  "NexMesh": {
    "Db": {
      "Type": "PostgreSQL",
      "ConnectionString": "Host=localhost;Database=myapp;Username=postgres;Password=xxx",
      "AutoSyncStructure": true,
      "WorkerId": 1
    }
  }
}
```

## NexMesh:AI（AI 管道）

| 键 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| DefaultProvider | string | main | 默认 Chat Provider 名称 |
| MaxToolsPerRequest | int | 10 | 工具数截断上限（防 Prompt 膨胀） |
| Providers.{name}.Type | string | — | stub（离线开发）/ openai-compatible（OpenAI/DeepSeek/Ollama） |
| Providers.{name}.Endpoint | string | — | API 端点（openai-compatible 必填） |
| Providers.{name}.ApiKey | string | — | API Key（支持 `${ENV\|}` 占位符） |
| Providers.{name}.Model | string | — | 模型名（必填） |

```json
{
  "NexMesh": {
    "AI": {
      "DefaultProvider": "deepseek",
      "MaxToolsPerRequest": 10,
      "Providers": {
        "stub":    { "Type": "stub", "Model": "stub" },
        "deepseek": {
          "Type": "openai-compatible",
          "Endpoint": "https://api.deepseek.com/v1",
          "ApiKey": "${NEXMESH_DEEPSEEK_KEY|}",
          "Model": "deepseek-chat"
        },
        "ollama": {
          "Type": "openai-compatible",
          "Endpoint": "http://localhost:11434/v1",
          "ApiKey": "",
          "Model": "qwen3:8b"
        }
      }
    }
  }
}
```

## NexMesh:Events(进程内事件总线)

| 键 | 默认 | 说明 |
|---|---|---|
| Capacity | 10000 | 有界队列容量;满则发布端回压等待(FullMode.Wait),不丢不静默 |
| Concurrency | 1 | 消费并行度(事件间并行,单事件内订阅者顺序执行) |

## NexMesh:Migrations(数据库版本化迁移)

| 键 | 类型 | 默认 | 说明 |
|---|---|---|---|
| Enabled | bool | false | true 时启动期自动执行待应用迁移(失败阻止启动);false 用显式 app.MigrateNexMeshAsync() |

迁移类继承 NexMeshMigration(Version/Name/Source/UpAsync/DownAsync),经 AddNexMeshMigrations(配置, 程序集) 扫描注册;记录表 nexmesh_migration 自动创建。策略名与约束见 docs/包实战案例.md 第 13 节。

## NexMesh:RateLimit(端点限流)

| 键 | 类型 | 默认 | 说明 |
|---|---|---|---|
| Policies:{name}:PermitLimit | int | 10 | 窗口内允许次数 |
| Policies:{name}:WindowSeconds | int | 60 | 窗口时长(秒) |
| Policies:{name}:Partition | Ip/User | Ip | 分区维度(User 取登录用户,匿名回退 IP) |

注意:策略名不可包含冒号(IConfiguration 层级分隔符),建议用短横线(如 demo-burst)。
契约方法标 [EnableRateLimiting("策略名")] 即生效;未调用 AddNexMeshRateLimiter 时管线不挂限流中间件(零影响)。

## NexMesh:Authentication:Oidc(外部 IdP 对接)

| 键 | 类型 | 默认 | 说明 |
|---|---|---|---|
| Issuer | string | — | IdP 签发方(iss 校验);配置+密钥即启用 |
| Audience | string | — | 受众(aud 校验);空不校验 |
| Secret | string | — | HS256 对称密钥(与 RsaPublicKeyPem 二选一) |
| RsaPublicKeyPem | string | — | RS256 公钥(PEM) |
| ClockSkewSeconds | int | 60 | 时钟偏移容忍 |

登录端点 POST nexmesh/auth/login 传 {"oidcToken":"<IdP的JWT>"} → 验证通过换发本地不透明令牌(滑动续期/吊销语义保留)。验证器零外部依赖(自研 HS256/RS256 + exp/nbf/iss/aud 校验)。

## NexMesh:GrpcPort(契约 gRPC 面)

| 键 | 默认 | 说明 |
|---|---|---|
| GrpcPort | 0(关) | >0 且装配 AddNexMeshGrpc 时 Kestrel 追加 Http2 监听 |

gRPC 面=通用网关(Invoke(service,method,args_json)→ApiResult 信封),业务契约零 proto 生成;建议内网部署,认证 header 与 REST 同构。
