# 快速开始

5 分钟跑通第一个 NexMesh AI 服务。

## 前置条件

- .NET 10 SDK
- 无需安装任何数据库（默认 SQLite 本地文件）
- 无需配置任何 AI Key（默认 Stub Provider 离线可跑）

## 方式一：脚手架（推荐）

```bash
dotnet new install ./templates/NexMesh.Templates/content
dotnet new nexmesh-ai -n MyApp
cd MyApp
dotnet run
```

打开 http://localhost:5180/health → `Healthy`

## 方式二：手动创建

```bash
dotnet new web -n MyApp
cd MyApp
```

引用包（推荐官方 NuGet；本地开发也可用项目引用）：

```xml
<ItemGroup>
  <PackageReference Include="NexMesh.Host" Version="0.0.4" />
  <PackageReference Include="NexMesh.Auth" Version="0.0.4" />
</ItemGroup>
```

创建 `Configs/appsettings.json`：

```json
{
  "NexMesh": {
    "Db": { "Type": "Sqlite", "ConnectionString": "Data Source=app.db", "AutoSyncStructure": true },
    "AI": {
      "DefaultProvider": "main",
      "Providers": {
        "main": { "Type": "stub", "Model": "stub" }
      }
    }
  }
}
```

`Program.cs`：

```csharp
using NexMesh.Host;

var builder = WebApplication.CreateBuilder(args);
builder.AddNexMeshService();   // 配置/约定注入/FreeSql/AI管道/缓存 全部隐形

var app = builder.Build();
app.UseNexMeshService();       // 上下文快照/异常/CORS/AutoApi/健康/文档
app.Run();
```

## 写第一个业务

接口契约即 API：定义 `IServiceApi` 接口 + `[Http*]` 标注，路由/绑定/授权/文档全自动。创建 `Features/Hello/HelloService.cs`：

```csharp
using Microsoft.AspNetCore.Mvc;
using NexMesh;                        // IServiceApi / [ApiContract] / PagedResult
using NexMesh.Core.DependencyInjection; // IScopedService

public record HelloDto(string Message);

public interface IHelloApi : IServiceApi
{
    [HttpPost]
    Task<HelloDto> SayAsync(string name);
}

public class HelloService : IHelloApi, IScopedService
{
    public Task<HelloDto> SayAsync(string name)
        => Task.FromResult(new HelloDto($"Hello, {name}!"));
}
```

路由约定：`api/{接口名去 I 去 Api}/{[Http*] 模板或方法名去 Async}` → 重启后自动可用：

```bash
curl -X POST "http://localhost:5180/api/hello/say?name=NexMesh"
# {"success":true,"code":0,"message":"","data":{"message":"Hello, NexMesh!"},"traceId":...,"timestamp":...}
```

- 响应统一 `ApiResult` 信封（成功 `code=0`，字段 camelCase）
- 接口名带命名空间不美观时用 `[ApiContract("hello")]` 自定义服务名
- 多参数复杂类型自动识别为 JSON Body，简单类型走 Query/路由

## 接入数据库（FreeSql 约定）

```csharp
public class Employee : ISoftDelete, IAudited, IUserAudited
{
    [Column(IsIdentity = true)]
    public long Id { get; set; }
    public string Name { get; set; } = "";
    public string Department { get; set; } = "";
    public bool IsDeleted { get; set; }      // 软删自动
    public DateTime CreateTime { get; set; } // 审计自动
    public string? CreateUserId { get; set; }// 操作人自动
}
```

框架自动接管：查询排除已删记录、写入填充审计字段、操作人取 ICurrentUser。

## 接入 AI 工具

```csharp
using NexMesh.AI.Tools;

public class OrderTools(IFreeSql db) : IScopedService
{
    [NexMeshTool("查询订单状态。低风险只读。", NexMeshRiskLevel.Low)]
    public async Task<string> QueryAsync(long orderId)
    {
        var order = await db.Select<Order>().Where(o => o.Id == orderId).FirstAsync();
        return order?.ToString() ?? $"订单 {orderId} 不存在";
    }
}
```

自动注册为 AI 可调用工具，经 Chat 端点 `/api/ai/chat` 可流式对话。

## 接入认证

```csharp
builder.Services.AddNexMeshAuth(builder.Configuration);
builder.Services.AddSingleton<ILoginValidator, MyValidator>();

app.UseNexMeshAuthentication();  // 须在 UseNexMeshService 之前
app.UseAuthorization();          // 显式钉住顺序
app.UseNexMeshService();
app.MapNexMeshAuth();            // /nexmesh/auth/login|logout|me
```

登录获取 Token 后，所有契约端点默认要求认证（默认拒绝；`[AllowAnonymous]` 显式放行）。

## 常用端点

| 端点 | 用途 |
|---|---|
| `GET /health` | 健康检查 |
| `GET /openapi/v1.json` | 契约 OpenAPI 文档（字段级 schema + XML 中文注释） |
| `/scalar` | Scalar 调试 UI（默认仅开发环境） |
| `POST /nexmesh/auth/login` | 登录获取 Token |
| `GET /nexmesh/auth/me` | 当前身份 |
| `POST /api/ai/chat` | 流式 AI 对话（SSE） |
| `GET /api/ai/tools` | 已注册 AI 工具清单 |
| `GET /api/approvals/pending` | 待审高危操作 |
| `POST /api/approvals/{id}/approve` | 批准执行 |
