# 快速开始

> 这篇文档假设你刚接触 NexMesh,甚至刚接触 .NET 不久。
> 跟着做,大约 15 分钟,你会得到一个**带认证、带数据库、带 AI 接口**的完整后端服务。
> 每一步都有"你应该看到什么"——对不上就停下来查,不要往下硬做。

## 开始之前:你需要准备什么

| 需要 | 怎么确认 | 没有的话 |
|---|---|---|
| .NET 10 SDK | 终端执行 `dotnet --version` 输出 `10.x` | 到 [dotnet.microsoft.com](https://dotnet.microsoft.com/download/dotnet/10.0) 下载安装 |
| 一个终端 | PowerShell / CMD / Git Bash 都行 | — |
| 能访问 NuGet | `dotnet add package Newtonsoft.Json` 不报错 | 配置公司镜像源 |

**不需要**:数据库(SQLite 文件自动创建)、AI 的 Key(离线演示模式)、Docker、Redis。

---

## 第 1 步:把示例跑起来(5 分钟,先看到效果再写代码)

```bash
git clone https://gitee.com/520vip/NexMesh.git
cd NexMesh/samples/NexMesh.AiDemo
dotnet run
```

**你应该看到**(滚过一堆日志后,最后几行类似):

```
info: Microsoft.Hosting.Lifetime[0]
      Now listening on: http://localhost:5000
```

> 端口号以你这台机器的 `Now listening on` 为准,下面命令里的端口照着改。

开一个**新的**终端窗口验证:

```bash
# 健康检查——能通就说明服务活着
curl http://localhost:5000/health
# 你应该看到:Healthy
```

浏览器打开 `http://localhost:5000/scalar`——这是自动生成的接口调试页面,所有接口都能在这里试。

**这一步意味着什么**:你没有配置任何数据库和 AI Key,但服务已经带着 3000 条演示数据和离线 AI 跑起来了。

<details>
<summary>❌ 报错了?点开对照</summary>

| 报错关键词 | 原因 | 解决 |
|---|---|---|
| `unable to bind to port` | 端口被占 | 改配置里的 `NexMesh:HttpPort` 换一个(比如 5099) |
| `dotnet: command not found` | SDK 未安装或没进 PATH | 重装 SDK,重开终端 |
| `NU1101/NU1301 无法找到包` | NuGet 源不通 | 公司网络配镜像源,或挂代理 |
| SQLite `disk I/O error` | 目录无写权限 | 把项目挪到可写目录 |

</details>

## 第 3 步:写第一个接口(不写 Controller、不配路由)

在项目里新建 `HelloService.cs`,整个文件如下,没有别的:

```csharp
using Microsoft.AspNetCore.Mvc;
using NexMesh;                         // IServiceApi / [ApiContract] 都在这里
using NexMesh.Core.DependencyInjection; // IScopedService 标记接口

// ① 声明接口(它就是 API 的"合同")
public interface IHelloApi : IServiceApi
{
    [HttpPost]
    Task<string> SayAsync(string name);
}

// ② 实现它(标 IScopedService,框架自动注册,不用写 AddScoped)
public class HelloService : IHelloApi, IScopedService
{
    public Task<string> SayAsync(string name)
        => Task.FromResult($"你好,{name}!");
}
```

重启服务(`Ctrl+C` 停掉再 `dotnet run`),然后调用:

```bash
curl -X POST "http://localhost:5000/api/hello/say?name=小白"
```

**你应该看到**:

```json
{"data":"你好,小白!","success":true,"code":0,"message":"","traceId":"...","timestamp":"..."}
```

**刚才发生了什么**:

- 你没写 Controller、没配路由、没注册 DI——框架扫描到 `IServiceApi` 接口就自动搞定;
- 路由规则:`api/` + 接口名去掉 `I` 和 `Api`(IHelloApi → `hello`)+ 方法名去掉 `Async`(SayAsync → `say`);
- 所有响应自动包成统一格式(`data/success/code/message/traceId`),前端只需要判断 `success`。

> 如果接口名想自定义(比如接口叫 `IHelloWorldV2Api` 但路由想要 `hello`),在接口上标 `[ApiContract("hello")]`。

## 第 4 步:接数据库(只写实体,不用建表)

新建 `Employee.cs`:

```csharp
using FreeSql.DataAnnotations;

public class Employee
{
    [Column(IsIdentity = true)]
    public long Id { get; set; }
    public string Name { get; set; } = "";
    public string Department { get; set;} = "";

    // 下面三个字段是框架约定:实现了软删除和审计
    public bool IsDeleted { get; set; }
    public DateTime CreateTime { get; set; }
    public string? CreateUserId { get; set; }
}
```

重启服务。**你会看到**:项目目录多了一个 `app.db` 文件(SQLite 数据库),表已自动建好(开发期 `AutoSyncStructure: true` 的效果;生产环境要关,后续版本提供正式迁移工具)。

在任意服务里注入 `IFreeSql` 就能查询:

```csharp
public class HelloService(IFreeSql db) : IHelloApi, IScopedService
{
    public async Task<string> SayAsync(string name)
    {
        var count = await db.Select<Employee>().CountAsync();
        return $"你好,{name}!库里现在有 {count} 条员工数据。";
    }
}
```

**框架自动帮你做的三件事**:查询自动排除已删除的记录;插入自动填 `CreateTime`;自动记录操作人 `CreateUserId`(登录后才有值,见下一步)。

## 第 5 步:加登录(不写登录页面逻辑,只写"怎么验证密码")

框架提供登录接口、令牌管理、限流,你只需要告诉它"这个密码对不对"。

`Program.cs` 加三行(在 `builder.Build()` 之前 / `app.Run()` 之前):

```csharp
builder.Services.AddNexMeshAuth(builder.Configuration);
builder.Services.AddSingleton<ILoginValidator, MyValidator>();   // 你写的密码校验

// app 阶段(注意顺序):
app.UseNexMeshAuthentication();
app.UseAuthorization();
// ...原有的 UseNexMeshService() 在这两行之后
app.MapNexMeshAuth();   // 挂载登录/登出/查身份三个端点
```

再写校验类(示例:固定账号,真实项目里查数据库):

```csharp
using NexMesh.Auth;

public class MyValidator : ILoginValidator
{
    public Task<LoginUser?> ValidateAsync(string username, string password)
        => Task.FromResult<LoginUser?>(
            username == "admin" && password == "123456"
                ? new("1", "管理员")        // 登录成功:返回用户身份
                : null);                     // 返回 null = 用户名或密码错误
    }
```

重启后:

```bash
# 登录拿令牌
curl -X POST http://localhost:5000/nexmesh/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"123456"}'
# 你应该看到:{"data":{"accessToken":"xxxxx",...},"success":true,...}

# 带令牌访问(没有令牌的请求现在会被拒绝——默认所有接口都要登录)
curl http://localhost:5000/api/hello/say?name=小白 \
  -H "Authorization: Bearer 把accessToken粘到这里"
```

**两个要点**:

- 默认**所有接口都要求登录**;想放开某个接口,在方法上标 `[AllowAnonymous]`;
- 同一 IP 一分钟内密码错 5 次会被限流 429,防止暴力破解(次数可在配置里调)。

## 第 6 步:接 AI(先离线跑,再换真模型)

把一个方法标上特性,它就成了"AI 可以调用的工具":

```csharp
using NexMesh.AI.Tools;

public class EmployeeTools(IFreeSql db) : IScopedService
{
    [NexMeshTool("按名字查员工信息。低风险只读。", NexMeshRiskLevel.Low)]
    public Task<string> QueryAsync(string name) { /* 查库返回文本 */ }
}
```

`Configs/AI` 配置里默认是 `stub`(离线假模型,用于开发联调)。想接真实模型(以 DeepSeek 为例),改配置:

```json
"NexMesh": {
  "AI": {
    "DefaultProvider": "deepseek",
    "Providers": {
      "deepseek": {
        "Type": "openai-compatible",
        "Endpoint": "https://api.deepseek.com",
        "ApiKey": "你的Key",
        "Model": "deepseek-flash"
      }
    }
  }
}
```

重启后,通过 Chat 端点对话,AI 会自动调用你标注的工具回答问题。

> **安全规则**:只读查询标 `Low`;凡是"删数据、退款、发通知"这类写操作,标 `NexMeshRiskLevel.High`——AI 触发时不会直接执行,而是生成一张"审批单",人在审批中心确认后才真正执行。详见[安全规范](安全规范.md)。

## 方式二:从空项目手动搭

不想用脚手架,想看清楚每一块:

```bash
dotnet new web -n MyApp
cd MyApp
dotnet add package NexMesh.Host --version 0.0.4
```

创建 `appsettings.json`:

```json
{
  "NexMesh": {
    "Db": { "Type": "Sqlite", "ConnectionString": "Data Source=app.db", "AutoSyncStructure": true },
    "AI": {
      "DefaultProvider": "main",
      "Providers": { "main": { "Type": "stub", "Model": "stub" } }
    }
  }
}
```

`Program.cs` 全部内容:

```csharp
using NexMesh.Host;

var builder = WebApplication.CreateBuilder(args);
builder.AddNexMeshService();   // 装配:配置/DI约定/数据库/AI管道/缓存

var app = builder.Build();
app.UseNexMeshService();       // 管线:上下文/异常/CORS/契约端点/健康检查/文档
app.Run();
```

`dotnet run` 起服务,回到本文[第 3 步](#第-3-步写第一个接口不写-controller不配路由)继续。
