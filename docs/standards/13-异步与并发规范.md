# 13 异步与并发规范

## async 纪律

- **[强制]** 全链路 async:端点 → Service → 仓储;**[禁止]** `.Result` / `.Wait()` / `GetAwaiter().GetResult()`(死锁 + 线程饥饿)
- **[强制]** `CancellationToken` 逐层透传(端点收 ct → 传给 repo/缓存/HTTP);**[禁止]** 吞 ct 自己 `CancellationToken.None`
- **[强制]** 异常处理保持异步(catch 里 await / throw;),不用 async void(事件处理器外的任何地方)

## 取消语义

- 客户端断开 → `OperationCanceledException` 由框架按取消处理,业务代码不需要(也不应该)catch 它转成 200/499

## 并发与批量

- **[强制]** 批量写用仓储批量方法(`AddManyAsync`/`UpdateManyAsync`);循环逐条 = N 次往返(1000 条差 100 倍)
- **[建议]** 多个独立 IO 用 `Task.WhenAll` 并行,但注意下游连接池上限(默认并发 ≤ 10 起步)
- **[禁止]** 无上限 `Parallel.ForEachAsync` 打数据库;并发度显式传参

## 后台任务

- **[强制]** 后台任务用 `BackgroundService`,循环内 `await Task.Delay(interval, ct)` 且响应 ct
- **[强制]** 停机优雅退出:收到取消即完成当前批次并退出;长任务实现进度落盘可续跑
- **[建议]** 单服务内异步解耦优先事件总线,不新造 Channel 队列
