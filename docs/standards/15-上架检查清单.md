# 15 上架检查清单(PR 合并与上线前自检)

> 全部勾完才能合并/上线。任何一项不满足,要么修,要么在 PR 里写明豁免理由与 owner。

## 功能与契约

- [ ] 新端点走 `/api/{resource}` 命名,DTO 不泄实体内部字段
- [ ] 分页用 `PagedResult` + `ToPagedResultAsync`,排序走白名单
- [ ] 错误码已登记 `docs/errorcodes.md`,消息面向调用方
- [ ] 破坏性变更已在 PR 标题标注并通知调用方

## 数据

- [ ] 实体按需实现 `ISoftDelete`/`IAudited`;删除为软删除(物理删除有审批依据)
- [ ] 多写操作有事务;跨服务动作在事务提交后走事件
- [ ] 主键用雪花/UUIDv7,无 `Guid.NewGuid()`

## 安全

- [ ] 端点默认受保护,匿名需显式 `AllowAnonymous`
- [ ] 资源级权限比对 `ICurrentUser`(越权 403)
- [ ] 无密钥/敏感信息入库入仓;日志敏感字段已脱敏
- [ ] 生产 `ExposeInternalErrors=false`

## 稳定性

- [ ] 缓存 Key 规范 + TTL + 写后失效;读走 `GetOrCreateAsync`
- [ ] 后台任务响应取消,优雅退出
- [ ] 无 `.Result`/`.Wait()`;ct 全链路透传
- [ ] 限流按路由评估(登录/开放接口已收紧)

## 可观测与部署

- [ ] 关键路径有 Information 级业务日志(结构化模板)
- [ ] `EnableOpenTelemetry` 开启,OTLP 指向 Collector
- [ ] `/health/ready` 反映真实依赖;Dockerfile 探针/graceful 配齐
- [ ] CI 绿(Release 零警告 + 测试全绿);新逻辑有测试

## 文档

- [ ] 包 README / 服务 README / errorcodes.md 同步更新
- [ ] 配置新增项已登记(默认值 + 说明)
