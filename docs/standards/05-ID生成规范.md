# 05 ID 生成规范

## 策略决策表

| 场景 | 策略 | 理由 |
|---|---|---|
| 数据库内部主键 | **雪花 long**(`NextSnowflakeId()`) | 趋势递增,索引友好,紧凑 |
| 对外暴露标识(URL/前端) | **UUIDv7**(`NextUuidV7()`)或雪花字符串 | 不暴露业务量级,UUIDv7 仍时间有序 |
| 分库分表键 | 雪花 long | 趋势递增利于分片 |
| 追踪/关联键 | 已有 TraceId 体系 | 别另造 |

## 规则

- **[强制]** 主键禁止 `Guid.NewGuid()`(v4 无序,B+ 树页分裂),显式取 `IIdGenerator`:

```csharp
public sealed class CreateOrder(IRepository<Order> repo, IIdGenerator ids) : ...
{
    var order = await repo.AddAsync(new Order { Id = ids.NextUuidV7(), ... });
}
```

- **[强制]** 多实例部署为每个实例配置不同 `WorkerId(0-63)`,由环境变量 `NexMesh__Ids__WorkerId` 注入(见部署规范)
- **[禁止]** 主键值参与业务语义(订单号 ≠ 主键;单号走独立序列/规则,存业务字段)
- **[建议]** 自增主键仅用于纯内部、无合并诉求的表;跨库同步场景一律雪花

## UUIDv7 说明

`Guid.CreateVersion7()`(RFC 9562)毫秒级时间戳前缀:全局唯一 + 时间有序,零依赖;需要纳秒排序或多实例单调递增时选雪花。
