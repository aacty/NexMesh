# 12 配置规范

## 结构

- **[强制]** 框架配置统一前缀 `NexMesh:*`(见各包 README 的节名);业务配置独立前缀(如 `Billing:*`),**[禁止]** 业务键混进 NexMesh 节
- **[强制]** 连接串放 `ConnectionStrings:{Name}`,与 NexMesh 数据源名对应

## 优先级与环境

```
环境变量 > appsettings.{Env}.json > appsettings.json > 代码默认值
```

- **[强制]** 环境变量双下划线分层:`NexMesh__Auth__Jwt__Key`、`NexMesh__Events__Transport`
- **[强制]** 本地覆盖写 `appsettings.local.json` 或 Development 节,该类文件不入库(.gitignore 已配)
- **[强制]** 每个 Environment 有独立 appsettings(Development/Production 至少两个)

## 校验与密钥

- **[强制]** `AddNexMesh(configuration)` 传入配置以启用启动验证——配置错启动即失败,不带病运行
- **[强制]** 密钥(JWT Key/ApiKey/DB 密码)只经环境变量或密钥管理注入;**[禁止]** 默认值兜底密钥(没配就抛错,而不是 dev-key 继续跑)
- **[建议]** 新增配置项必须同时给:默认值说明 + README 登记 + 启动验证(枚举/范围)

## 外部依赖开关(零基础设施原则)

Redis/RabbitMQ/OTLP 未配置时框架自动降级,降级行为必须可在配置里显式控制(Mode 强制/自动),不搞隐式探测。
