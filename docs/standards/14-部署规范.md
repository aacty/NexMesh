# 14 部署规范

容器镜像、探针、优雅关闭与配置清单的完整操作见 **[部署指南](../部署指南.md)**,本篇是合并门禁级要求。

## 镜像

- **[强制]** 多阶段构建(sdk 构建层 / aspnet 运行层),运行层不含 SDK 与源码
- **[强制]** 镜像 tag 用版本号或 commit sha,**[禁止]** latest 上生产
- **[强制]** 配置全量环境变量注入,镜像内不含环境差异(一份镜像走所有环境)

## 探针与可用性

- **[强制]** liveness `/health`、readiness `/health/ready`;readiness 必须包含关键依赖(数据库)检查
- **[强制]** `terminationGracePeriodSeconds ≥ 30`,保证滚动更新不丢在途请求
- **[强制]** 资源 requests/limits 显式声明(CPU/内存),避免节点挤兑

## 数据与安全

- **[强制]** 数据库迁移(CodeFirst 结构变更)有评审:加列可空/有默认,删列走两段式(先停写→下版再删)
- **[强制]** 生产密钥不进 CI 变量明文;JWT Key 定期轮换(见认证规范 08)
- **[强制]** 对外端口最小暴露:业务 8080 + 健康检查;调试端点(/scalar)**[禁止]** 生产直暴(网关层屏蔽或加授权)

## 发布节奏

- **[强制]** 上线前过 [15-上架检查清单](15-上架检查清单.md)
- **[建议]** 灰度:新版本先 1 实例观察错误率/延迟,再全量
