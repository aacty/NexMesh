# NexMesh 错误码登记表

> 规范 04 强制:每个服务维护本文件,新错误码必须同步登记;已发布不可改语义。

## 框架保留码(NexMesh 包自用)

| 码 | 含义 | 抛出位置 | 包 |
|---|---|---|---|
| 40002 | 金额/参数业务校验失败 | 业务端点 | (示例) |
| 40010 | 非法排序字段(白名单外) | OrderByWhitelist | Data.FreeSql |
| 40020 | 实体未实现 ISoftDelete,不能软删除 | SoftDeleteAsync | Data.FreeSql |
| 40101 | 未认证或令牌已过期 | OnChallenge | Auth |
| 40401 | 资源不存在(通用) | 业务端点 | — |
| 40901 | 重复提交(幂等防重) | IdempotencyMiddleware | Cache |
| 40902 | 数据并发冲突(乐观锁戳不匹配) | UpdateAsync(CAS) | Data.FreeSql |
| 500 | 服务器内部错误(未知异常,不泄露细节) | ExceptionHandlingMiddleware | Core |

## 段位规则(5 位,HTTP 对齐前缀)

| 段 | 含义 | 示例 |
|---|---|---|
| 400xx | 请求/参数问题 | 40001 参数格式、40002 业务校验、40010 非法排序 |
| 401xx | 未认证 | 40101 token 无效/过期 |
| 403xx | 已认证无权限 | 40301 角色不足 |
| 404xx | 资源不存在 | 40401(框架保留:通用不存在)40402 起服务自定义 |
| 409xx | 冲突 | 40901 重复提交、40902 状态/并发冲突 |
| 5xxxx | 内部错误 | 500(框架固定) |
