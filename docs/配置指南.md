# NexMesh 配置指南

五种方式管理配置和密钥,按场景选。

---

## 方式对比

| 方式 | 适合场景 | 好处 |
|---|---|---|
| **.env 文件** | 本地开发 | 项目根目录一个文件,不入 Git,改了重启就生效 |
| **User Secrets** | 本地开发(团队) | 每人自己的密钥,不在代码里,不在 Git 里 |
| **简化环境变量** | 生产部署 | `NEXMESH_JWT_KEY` 一行搞定,不需要写 `NexMesh__Auth__Jwt__Key` |
| **appsettings.Production.json** | 服务器部署 | 文件放服务器上,不入 Git |
| **Azure Key Vault 等** | 企业级 | 集中管理,自动轮换,审计日志 |

---

## 方式一:.env 文件(推荐开发用)

### 使用

在项目根目录创建 `.env` 文件:

```bash
# .env(不要提交到 Git!)
NEXMESH_JWT_KEY=my-dev-secret-key-at-least-32-characters
NEXMESH_DB=Server=localhost;Database=orders;Uid=root;Pwd=123456
NEXMESH_REDIS=localhost:6379
# NEXMESH_MQ=localhost
# NEXMESH_OTLP=http://localhost:4317
```

Program.cs 加一行:

```csharp
var builder = WebApplication.CreateBuilder(args);
builder.LoadNexMeshEnv();    // ← 加这一行,自动读取 .env
// ... 其他 Add 方法
```

确保 `.gitignore` 里有:

```
.env
```

### 支持的简化变量名

| 变量名 | 对应配置 | 说明 |
|---|---|---|
| `NEXMESH_JWT_KEY` | NexMesh:Auth:Jwt:Key | JWT 密钥 |
| `NEXMESH_JWT_ISSUER` | NexMesh:Auth:Jwt:Issuer | JWT 签发者 |
| `NEXMESH_JWT_EXPIRY` | NexMesh:Auth:Jwt:ExpiryMinutes | 过期分钟数 |
| `NEXMESH_DB` | ConnectionStrings:Main | 主库连接串 |
| `NEXMESH_DB_SLAVE` | ConnectionStrings:Slave | 从库连接串 |
| `NEXMESH_REDIS` | NexMesh:Cache:Sources:main:ConnectionString | Redis 地址 |
| `NEXMESH_MQ` | NexMesh:Events:RabbitMqHostName | RabbitMQ 地址 |
| `NEXMESH_MQ_USER` | NexMesh:Events:RabbitMqUserName | MQ 用户名 |
| `NEXMESH_MQ_PASS` | NexMesh:Events:RabbitMqPassword | MQ 密码 |
| `NEXMESH_OTLP` | NexMesh:Observability:OtlpEndpoint | OTLP Collector |

没在表里的变量:自动把 `__` 替换为 `:`,如 `MY__CUSTOM__KEY → MY:CUSTOM:KEY(仅替换双下划线)`。

### 优先级

```
系统环境变量 > .env 文件 > appsettings.json.{Env}.json > appsettings.json
```

.env 不会覆盖已有的系统环境变量(安全:生产环境设置了的环境变量优先)。

## 方式二:User Secrets(团队开发)

每个开发人员有自己的密钥,不在代码里:

```bash
# 初始化(只需一次)
dotnet user-secrets init

# 设置值
dotnet user-secrets set "NexMesh:Auth:Jwt:Key" "my-dev-secret-at-least-32-characters"
dotnet user-secrets set "ConnectionStrings:Main" "Server=localhost;Database=orders;Uid=root;Pwd=my-dev-password"

# 查看已设置的
dotnet user-secrets list

# 删除
dotnet user-secrets remove "NexMesh:Auth:Jwt:Key"
```

密钥存在本机 `%APPDATA%\Microsoft\UserSecrets\{项目GUID}\secrets.json`,不进代码,不进 Git。

**不需要在 Program.cs 加任何代码**——ASP.NET Core 在 Development 环境自动加载 User Secrets。

## 方式三:简化环境变量(生产部署)

### 之前(丑):

```bash
# Docker
docker run -e NexMesh__Auth__Jwt__Key="xxx" ...

# Windows PowerShell
[Environment]::SetEnvironmentVariable("NexMesh__Auth__Jwt__Key", "xxx", "Machine")

# Linux systemd
Environment=NexMesh__Auth__Jwt__Key=xxx
```

### 现在(干净):

```bash
# Docker
docker run -e NEXMESH_JWT_KEY="xxx" ...

# Windows PowerShell
[Environment]::SetEnvironmentVariable("NEXMESH_JWT_KEY", "xxx", "Machine")

# Linux systemd
Environment=NEXMESH_JWT_KEY=xxx

# K8s
env:
  - name: NEXMESH_JWT_KEY
    valueFrom: { secretKeyRef: { name: my-secrets, key: jwt-key } }
```

两种写法都支持(简化名自动映射到完整路径)。

## 方式四:appsettings.Production.json(服务器部署)

在服务器上放一个文件,不入 Git:

```json
// appsettings.Production.json(只在服务器上,不在代码仓库里)
{
  "ConnectionStrings": {
    "Main": "Server=prod-db;Database=orders;Uid=prod;Pwd=real-password"
  },
  "NexMesh": {
    "Auth": {
      "Jwt": { "Key": "production-secret-key-at-least-32-characters" }
    },
    "Cache": {
      "Sources": {
        "main": { "ConnectionString": "prod-redis:6379" }
      }
    }
  }
}
```

设置环境变量 `ASPNETCORE_ENVIRONMENT=Production`,框架自动读取。

## 方式五:Azure Key Vault(企业级)

```csharp
builder.Configuration.AddAzureKeyVault(
    new Uri("https://myvault.vault.azure.net/"),
    new DefaultAzureCredential());
```

然后 Key Vault 里的 secret 名用 `NexMesh--Auth--Jwt--Key`(双横线替代双下划线)。

## 完整配置项参考

| 配置路径 | 简化环境变量 | 默认值 | 说明 |
|---|---|---|---|
| `ConnectionStrings:Main` | `NEXMESH_DB` | — | 主库连接串 |
| `ConnectionStrings:Slave` | `NEXMESH_DB_SLAVE` | — | 从库(读分离) |
| `NexMesh:Auth:Jwt:Key` | `NEXMESH_JWT_KEY` | — | JWT 密钥(≥32字符,必填) |
| `NexMesh:Auth:Jwt:Issuer` | `NEXMESH_JWT_ISSUER` | nexmesh | 签发者 |
| `NexMesh:Auth:Jwt:ExpiryMinutes` | `NEXMESH_JWT_EXPIRY` | 120 | 过期分钟数 |
| `NexMesh:Cache:Sources:main:ConnectionString` | `NEXMESH_REDIS` | null(用内存) | Redis 地址 |
| `NexMesh:Events:Transport` | — | Memory | Memory / RabbitMQ |
| `NexMesh:Events:RabbitMqHostName` | `NEXMESH_MQ` | localhost | MQ 地址 |
| `NexMesh:Observability:OtlpEndpoint` | `NEXMESH_OTLP` | null | OTLP Collector |
| `NexMesh:RateLimiting:PermitLimit` | — | 100 | 每窗口最大请求数 |
| `NexMesh:RateLimiting:WindowSeconds` | — | 60 | 窗口秒数 |
| `NexMesh:Docs:EnableInProduction` | — | false | 生产开启 /scalar |
| `NexMesh:Diagnostics:EnableInProduction` | — | false | 生产开启 /diagnostics |

## 快速选择

```
写代码时 → .env 文件(一个文件搞定,不入 Git)
团队协作 → User Secrets(每人独立密钥)
Docker/K8s → 简化环境变量(NEXMESH_JWT_KEY=xxx)
传统服务器 → appsettings.Production.json(文件放服务器)
大型企业 → Azure Key Vault(集中管理+审计)
```
